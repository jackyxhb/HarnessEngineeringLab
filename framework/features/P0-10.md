# P0-10. Inter-Agent Communication (The Mailbox)

> **Chain:** [EP-5](../principles/EP-05.md) → Coordination cost must stay bounded

## L2: Targeted Enhancement

Agents can coordinate without supervisor bottleneck, with bounded message overhead.

## L3: Design Decisions

Shared message queue/mailbox; defined message schema (sender, receiver, type, payload, timestamp); P2P, broadcast, idle notification strategies.

## L4: Concrete Actions & Tools

- **Action:** Implement a shared message queue or mailbox file that agents poll for directives.
- **Action:** Define message schema (sender, receiver, type, payload, timestamp).
- **Action:** Add P2P, broadcast, and idle notification communication strategies.
- **Tool:** Inter-agent messaging middleware.
- **Tool:** Message queue implementations (file-based or pub/sub).

## L4: Prevention

- **No specific prevention items.** Communication failures are caught by orchestration-level gap signals (P0-5).

## L5: Gap Signals

- Agents coordinate only through shared files, with no structured messaging
- No mechanism for direct peer-to-peer communication between agents
- Broadcasting important state changes requires manual orchestrator intervention
- Idle agents have no way to signal availability to the swarm
- Task handoffs lose context because there is no message protocol

## L5: Improvement Policies

| Tier | Action | Dimensions |
| ------ | -------- | ------------ |
| 1 | Implement a shared message queue or mailbox file that agents poll for directives | Maturity |
| 1 | Define message schema (sender, receiver, type, payload, timestamp) | Effectiveness |
| 2 | Add peer-to-peer (P2P), broadcast, and idle notification communication strategies | Scalability |
| 2 | Implement message acknowledgment and delivery guarantees | Risk |
| 3 | Build adaptive routing that selects communication strategy based on topology | Scalability, Cost |

## L5: Measurement

- P2P message delivery latency < N seconds
- 0 lost messages
- Broadcast fan-out complete within 1 cycle

## Dependencies

**Required by:** P0-5 Orchestration Logic (for topology management)
**Interacts with:** P1-7 Planning, Task Lists & Blackboards (for task claiming)
