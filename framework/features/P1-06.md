# P1-6. Web Search & MCP Integration

> **Chain:** [EP-12](../principles/EP-12.md) → Finite attention demands active management

## L2: Targeted Enhancement

Agent answers reflect current state of the world.

## L3: Design Decisions

Web search tool integration; MCP server connections for domain-specific context; caching layer; relevance filtering; machine-readable MCP capability manifests; Machine-Readability First.

## L4: Concrete Actions & Tools

- **Action:** Give agents access to real-time knowledge and current data beyond their training cutoff.
- **Tool:** Web Search tools.
- **Tool:** Model Context Protocol (MCP) servers (e.g., Context7).

## L4: Prevention

- **`P1-6` Prevent Knowledge Silos:** You must prevent agents from being limited to their internal training data for fast-moving topics. Mandate web-search or MCP-knowledge retrieval for external research tasks.
- **`P1-6` Prevent Narrative MCP Server Manifests:** MCP server configurations and capability definitions must follow a machine-readable JSON format to ensure automated tool-binding.

## L5: Gap Signals

- Agent produces outdated answers for rapidly evolving domains
- No access to external APIs, documentation, or real-time data
- Agent cannot look up library versions or API changes
- Agent hallucinates information that is available via search
- MCP integrations are brittle and require manual configuration
- Knowledge retrieval overhead exceeds reasoning benefits
- No audit trail of external data used in decision making
