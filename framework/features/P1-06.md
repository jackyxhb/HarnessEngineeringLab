# P1-6. Web Search & MCP Integration

> **Chain:** [EP-13](../principles/EP-13.md) → Current signals outperform stale snapshots

## L2: Targeted Enhancement

Agent answers reflect current state of the world, not stale training data.

## L3: Design Decisions

Web search tool integration; MCP server connections for domain-specific context; caching layer; relevance filtering.

## L4: Concrete Actions & Tools

- **Action:** Give agents access to real-time knowledge and current data beyond their training cutoff.
- **Tool:** Web Search tools.
- **Tool:** Model Context Protocol (MCP) servers (e.g., Context7).

## L4: Prevention

- **No specific prevention items.**

## L5: Gap Signals

- Agent produces outdated answers for rapidly evolving domains
- No access to external APIs, documentation, or real-time data
- Agent cannot look up library versions or API changes

## L5: Improvement Policies

| Tier | Action | Dimensions |
| ------ | -------- | ------------ |
| 1 | Integrate web search tool into agent's available tools | Maturity |
| 2 | Connect MCP servers for domain-specific external context | Effectiveness |
| 2 | Add caching layer to reduce redundant external lookups | Cost |
| 3 | Build relevance filtering — agent decides when external search adds value | Effectiveness |

## L5: Measurement

- Outdated-answer rate → 0 for rapidly evolving domains
- External lookup cache hit rate > 60%

## Dependencies

**Largely independent.** Interacts with P1-3 Tool Offloading — search results can be noisy.
