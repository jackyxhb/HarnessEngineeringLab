# P3-4. Consolidation Loop

> **Chain:** [EP-19](../principles/EP-19.md) → Documentation must live with the code

## L2: Targeted Enhancement

Core system documentation automatically stays in sync with codebase.

## L3: Design Decisions

Auto-update triggers for canonical docs (AGENTS.md, README, HarnessConfig.json); ADR prompts for new patterns; changelog accumulation; version-tagged documentation snapshots.

## L4: Concrete Actions & Tools

- **Action:** Implement a consolidation loop that auto-updates canonical documentation (AGENTS.md, README, HarnessConfig.json) when features land.
- **Action:** Prompt for ADR (Architecture Decision Record) creation when new patterns are introduced.
- **Action:** Accumulate changelogs automatically from commit messages.
- **Tool:** Consolidation scripts that verify and update doc counts, feature lists, and configs.
- **Tool:** ADR templates and prompts.
- **Tool:** Changelog generation tools.

## L4: Prevention

- See P3-2 prevention: Documentation Disconnects prevention applies jointly to P3-2 and P3-4.

## L5: Gap Signals

- AGENTS.md feature count doesn't match actual feature files
- New patterns introduced without ADR
- Changelogs are manually maintained and frequently incomplete
- Configuration files drift from actual system state

## L5: Improvement Policies

| Tier | Action | Dimensions |
| ------ | -------- | ------------ |
| 1 | Build consolidation scripts that verify doc counts and feature lists | Maturity |
| 1 | Prompt for ADR creation when new patterns are introduced | Risk |
| 2 | Automate changelog generation from commit messages | Effectiveness |
| 2 | Add CI check that verifies AGENTS.md counts match actual files | Risk, Scalability |
| 3 | Build self-healing documentation that auto-updates from code analysis | Scalability |

## L5: Measurement

- Doc-to-code count discrepancy → 0
- ADR coverage for new patterns > 90%
- Changelog completeness > 95%

## Dependencies

**Requires:** P3-2 Documentation Sync
**Feeds back to:** P1-1 Repository as Truth — the loop keeps the canonical source current
