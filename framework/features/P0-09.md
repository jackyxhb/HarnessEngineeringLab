# P0-9. Smart Command Wrappers

> **Chain:** [EP-9](../principles/EP-09.md) → Standard operations reduce variance

## L2: Targeted Enhancement

Zero variance in common CLI workflow execution.

## L3: Design Decisions

Intelligent multi-step workflows (`ccp`, `ccpr`, `reconcile`) located in `.agent/workflows/`; shift-left cost stratification (smoke < check < audit < LLM review); stable command names across versions.

## L4: Concrete Actions & Tools

- **Action:** Install and maintain canonical HE workflows (`ccp.md`, `ccpr.md`, `reconcile.md`) under `.agent/workflows/`.
- **Action:** Integrate agent reasoning into workflows (auto-generating comments/release notes).
- **Action:** Stratify commands by cost tier: smoke (< 2s, pre-commit) → check (< 30s, pre-push) → audit (< 60s, on-demand) → LLM review (expensive, last resort).
- **Tool:** Markdown workflow definitions (`.agent/workflows/ccp.md`, `ccpr.md`, `reconcile.md`).
- **Tool:** npm scripts (`npm run smoke`, `npm run check`, `npm run audit`).
- **Tool:** `Justfile` recipe definitions for multi-step task consolidation.

## L4: Prevention

- **`P0-9` Prevent Manual, Error-Prone CLI Execution:** You must prevent agents from manually executing raw, multi-step system commands (git, npm, shell) without standardization. Prevent this by mandating Smart Custom CLI proxies (e.g. `npm run check` instead of raw markdownlint); intent-based wrappers; consolidated multi-step operations; JSON-standardized command output for agent parsing; Machine-Readability First.

## L5: Gap Signals

- Agents consistently fail on complex CLI flag syntax
- Command output is too long for the context window
- No standard "safe" version of destructive commands
- Intent of agent actions is obscured by raw command noise
- High variation in commit message quality and release note detail
- Coordination overhead from agents mis-ordering system commands
