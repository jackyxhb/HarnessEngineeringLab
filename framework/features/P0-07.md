# P0-7. Escalation Policies & Audit Trails

> **Chain:** [EP-7](../principles/EP-07.md) → Every action must be traceable

## L2: Targeted Enhancement

Every agent action is attributable; stuck agents are detected and escalated within defined time bounds.

## L3: Design Decisions

Escalation triggers (N failures, time limits, loop detection); tiered escalation chains (retry → different agent → human); strict audit logs.

## L4: Concrete Actions & Tools

- **Action:** Define escalation triggers (N consecutive test failures, time limits, loop detection).
- **Action:** Route stuck tasks to human via notification (Slack, email, dashboard).
- **Action:** Implement tiered escalation (retry → different agent → human).
- **Tool:** Notification integrations (Slack, email, dashboard alerts).
- **Tool:** Audit trail logging systems.

## L4: Prevention

- **`P0-7` Prevent Opaque Decision-Making:** You must prevent decentralized unaccountability, where it is impossible to know _which_ agent made a harmful decision. Prevent this by enforcing strict audit trails that log every tool call, state transition, and inter-agent influence.

## L5: Gap Signals

- Agent loops indefinitely on unsolvable problems
- No notification when agent is stuck
- Human discovers failures hours or days later
- No defined threshold for "stuck" vs. "still working"

## L5: Improvement Policies

| Tier | Action | Dimensions |
| ------ | -------- | ------------ |
| 1 | Define escalation triggers (N consecutive test failures, time limits, loop detection) | Maturity, Risk |
| 1 | Route stuck tasks to human via notification (Slack, email, dashboard) | Effectiveness |
| 2 | Implement tiered escalation (retry → different agent → human) | Scalability |
| 3 | Add escalation analytics to identify systemic failure patterns | Human Role |

## L5: Measurement

- Time-to-escalation < N minutes (configurable)
- 100% of actions audit-logged
- 0 unattributed actions in the system

## Dependencies

**Requires:** P0-3 Verification (to detect failure), P1-5 Observability (for monitoring)
