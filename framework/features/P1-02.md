# P1-2. Context Compaction & Memory Management

> **Chain:** [EP-12](../principles/EP-12.md) → Finite attention demands active management

## L2: Targeted Enhancement

Sustained reasoning quality across long tasks.

## L3: Design Decisions

ConvStrategy for managing token limits; periodic summarization of long conversations; explicit memory anchors for key decisions; machine-readable context snapshots; Machine-Readability First.

## L4: Concrete Actions & Tools

- **Action:** Actively manage "context rot" by intelligently summarizing and separating short-term memory (session history) from long-term memory.
- **Tool:** Vector Databases to index past interactions and retrieved documents for long-term memory retrieval.

## L4: Prevention

- **`P1-2` Prevent Context Overflow:** You must prevent agents from hitting context window limits by mandating periodic summaries and clear-cuts of irrelevant history. All summaries must be anchored in the repository (`docs/`).
- **`P1-2` Prevent Narrative Context Summaries:** Context summaries and memory anchors must follow a machine-readable JSON format to enable automated context-restoration and pruning.

## L5: Gap Signals

- Agent loses track of key decisions made early in the conversation
- Conversation length causes significant latency and cost
- Token limits prevent agent from processing large codebases
- Important context is buried in narrative history
- No summarization or offloading of old context
