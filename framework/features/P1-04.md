# P1-4. Progressive Skills

> **Chain:** [EP-12](../principles/EP-12.md) → Finite attention demands active management

## L2: Targeted Enhancement

Only task-relevant capabilities are in context at any time.

## L3: Design Decisions

Modular skill architecture; iterative skill refinement; skills-as-code; machine-readable skill capability maps; Machine-Readability First.

## L4: Concrete Actions & Tools

- **Action:** Apply "progressive disclosure" to prevent context degradation from loading too many tools at startup.
- **Action:** Load specific skill front-matter into context only when an agent is assigned a task requiring that role.
- **Tool:** Modular skill and tool configuration files.

## L4: Prevention

- **No specific prevention items.** Absence is detected by gap signals.

## L5: Gap Signals

- Skills contain too many instructions for the context window
- Iterative improvements to skills are not versioned or tracked
- Skill dependencies are not explicitly defined or managed
- Agent fails to select the optimal skill for a given task
