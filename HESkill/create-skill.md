  3) Got user's permission, execute implementation plan in multiple agents mode, finally create summary for each modifications to
  acknowledge previou found CLUEs; workout assessment report again as final step to emphasize and show where and what these
  changes are.
- Scope:
  - Harness Engineering methodology has detailed information that could be found in this workspace.
- Methodologies:
  - Harness Engineering could involv multiple dimensions:
    1) feature tree(function area, core features, do or not do, recomendation and actions)
