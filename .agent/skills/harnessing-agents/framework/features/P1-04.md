# P1-4. Progressive Skills

> **Chain:** [EP-12](../principles/EP-12.md) → Finite attention demands active management

## L2: Targeted Enhancement

Only task-relevant capabilities are in context at any time.

## L3: Design Decisions

Modular skill architecture; iterative skill refinement; skills-as-code; machine-readable skill capability maps; Machine-Readability First.

## L4: Concrete Actions & Tools

- **Action:** Apply "progressive disclosure" to load only task-relevant skills at assignment time.
  - **Tool:** Skill loading mechanism: YAML metadata files in `.agent/skills/<skill_id>/` with headers: `name`, `version`, `description`, `user-invocable`, `allowed-tools`, `context-tokens`, `modes` (Full/Targeted).
  - **Tool:** Skill router logic: given a task type, read `.harness/mcp-capabilities.json`, match task keywords to skill `allowed-tools`, load only skills needed for the task.
  - **Acceptance Criteria:** Only task-relevant skills are loaded; startup skill context is minimal (< 5% of context window); irrelevant tool instructions are never in context.

- **Action:** Organize tools into role-based skill modules.
  - **Tool:** Skill module organization: skills grouped by role (e.g., `git-operations`, `code-review`, `documentation`, `testing`), each with independent config file.
  - **Tool:** Skill dependency map: `.agent/skills/skill-dependency-map.json` defines which tools each skill depends on; router uses this to load skill + dependencies only when needed.
  - **Acceptance Criteria:** Each skill is self-contained; skill loading is deterministic; no circular dependencies.

- **Action:** Measure context efficiency of skill loading.
  - **Tool:** Context efficiency metrics tracked in `.harness/skill-performance.jsonl`: timestamp, skill_id, task_type, tokens_loaded, tokens_used, selection_accuracy, success_rate.
  - **Tool:** Measurement rule: at end of task, log whether the selected skill was optimal; calculate `selection_accuracy = (correct_selections / total_selections) * 100%`.
  - **Acceptance Criteria:** Skill-selection accuracy > 90%; context efficiency ratio (tokens_used / tokens_loaded) > 0.8 (i.e., agent uses > 80% of loaded context).

## L5: Gap Signals

- Skills contain too many instructions for the context window
- Iterative improvements to skills are not versioned or tracked
- Skill dependencies are not explicitly defined or managed
- Agent fails to select the optimal skill for a given task
