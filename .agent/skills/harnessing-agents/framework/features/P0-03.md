## L4: Prevention

- **`P0-3` Prevent Unverified Commits:** All code must pass 'npm run smoke' and 'npm run check' before it is committed or pushed. Enforce this with pre-commit hooks and CI gates.
  - **Tool:** Git pre-commit hook (`.git/hooks/pre-commit`) runs `npm run smoke` (he-lint.js only, ~2s).
  - **Tool:** Git pre-push hook runs `npm run check` (markdownlint + cspell + he-lint, ~5s).
  - **CI Gate:** GitHub Actions workflow blocks merge if any of the above fail.
  - **Acceptance Criteria:** No commit reaches the repository history without passing `npm run smoke`; no push to main without passing `npm run check`.
  - **Registry Status:** `implemented` — pre-commit hooks enforce binary pass/fail.

- **`P0-3` Prevent Non-Deterministic Verification:** Verification signals must be machine-parseable (Exit 0/1) with JSON failure reports where applicable.
  - **Tool:** All npm scripts in `package.json` exit with binary codes (0 = success, non-zero = failure).
  - **Tool:** `npm run check` produces exit codes with binary semantics (0 = all checks pass, non-zero = failure).
  - **Acceptance Criteria:** `npm run smoke` exit code matches test outcome; no ambiguous or warning-level results permitted.
  - **Registry Status:** `implemented` — all verification scripts produce deterministic binary exit codes.

- **`P0-3` Prevent Cascading Hallucinations (Error Propagation):** Pre-commit hooks for unit/integration/E2E tests; required 'npm run audit' before merging; automated linting and structural checks; collective verification in MAS; Machine-Readability First.
  - **Tool:** Pre-commit hook + CI gate enforce `npm run check` binary pass/fail.
  - **Tool:** `npm run audit` validates structural harness integrity (`.harness/` files, REVIEWS.md, etc.) before merge.
  - **Tool:** Escalation events logged to `.harness/escalation-events.jsonl` with agent-id and failure reason for audit trail.
  - **Acceptance Criteria:** All errors are caught before reaching main; escalation event count < 3 per feature per sprint; zero defects escape to main without prior test execution.
  - **Registry Status:** `implemented` — pre-commit + CI gates + audit script form a multi-layer prevention chain.
