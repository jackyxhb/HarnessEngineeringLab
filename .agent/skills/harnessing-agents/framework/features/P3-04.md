## L2: Targeted Enhancement

## L3: Design Decisions

Auto-update triggers for canonical docs (AGENTS.md, README, HarnessConfig.json); ADR prompts for new patterns; changelog accumulation; version-tagged documentation snapshots.

## Scope: SAS vs MAS

**SAS Scope:** In single-agent mode, this feature runs a scheduled consolidation loop that audits drift between canonical framework files and live implementation, automatically updates documentation (AGENTS.md, README, HarnessConfig.json), and detects concept redundancies. The single agent executes the full audit-and-reconcile cycle, writing machine-readable consolidation records to track what was harmonized.

**MAS Scope:** In multi-agent mode, this feature enables distributed agents to trigger consolidation updates asynchronously when features land, with a dedicated consolidation-loop coordinator agent that aggregates findings from multiple streams, resolves conflicts through distributed consensus, and harmonizes framework state across all agents' local views via P0-9 Inter-Agent Communication.

**Transition Path:** Move from SAS scheduled audits to MAS distributed consensus by replacing the single scheduled loop with event-driven triggers (feature-landed events from any agent), establishing a consolidation-coordinator role to aggregate cross-agent updates, and implementing conflict-resolution logic for concurrent documentation updates.

## L4: Concrete Actions & Tools

- **Action:** Implement a consolidation loop that auto-updates canonical documentation (AGENTS.md, README, HarnessConfig.json) when features land.
- **Action:** Prompt for ADR (Architecture Decision Record) creation when new patterns are introduced.
- **Action:** Accumulate changelogs automatically from commit messages.
- **`P3-4` Prevent Concept Forking:** You must prevent the creation of redundant or overlapping features, principles, or docs. Run weekly consolidation loops to merge similar concepts and resolve chain gaps.
- **`P3-4` Prevent Narrative Consolidation Records:** Consolidation audit results and reconciliation actions must follow `.harness/consolidation-audit-report.schema.json` and `.harness/adr-record.schema.json` to enable automated health-tracking.
- **Tool:** Changelog generation tools.
