# /create-skill

Rebuild the harnessing-agents skill with all related documents in this project:

- Goal: to enhance target project to be harnessed with the highest level of mature degree.
- Steps:
  1. Inspect target workspace to collect clues of potential gaps, in multiple agents mode, reduced into one document: HE-CLUES.md;
  2. Based on found clues, work out recommendations, as well as their critical level, advise priority level of fixing them, all of these are used to produce an implementation plan, confirm or clarify with user, then based on user selections or decisions, revise implementation plan and show latest version;
  3. With user's permission, execute implementation plan in multiple agents mode, finally create summary for each modification to acknowledge previously found CLUEs; work out assessment report again as final step to emphasise and show where and what these changes are.
- Scope:
  - Harness Engineering methodology has detailed information that could be found in this workspace.
- Methodologies:
  - Harness Engineering involves multiple dimensions:
    1. Feature tree (function area, core features, do or not do, recommendation and actions)
    2. Agent scale (single agent system, small group agents, enterprise-level agents, scaled-swarm)
    3. Project complexity (pure in-hands/text operations, much on scripts operations, normal/simple software development, complicated software system development, large-scale enterprise project development)
    4. Remediation level (light — revise meta docs, medium — add new features, heavy — reform project architecture)
